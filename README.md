# 7amoHost Bot

1. افتح `.env` واملأ `DISCORD_TOKEN` و`AUTO_UPLOAD_CHANNEL_IDS` فقط. لو عندك أكثر من روم، افصل المعرفات بفاصلة.
2. افتح CMD داخل مجلد المشروع وشغّل:

```bat
npm install
npm start
```

لازم تفعّل **Message Content Intent** من Discord Developer Portal، وتمنح البوت صلاحية مشاهدة الروم وإرسال الرسائل وإرفاق الملفات. البوت يرفع مرفقات الصور والفيديوهات والملفات التي تقبلها Catbox تلقائيًا؛ حد الملف المحلي 190 MiB، وبعض الامتدادات محظورة من الخدمة نفسها. احتفظ بنسخة من الملفات المهمة.
